Detailed Description

A view into a Document.

Warning
If the document that a View instansce is pointing to is destroyed, using the View will result in "use after free".
Note
As the constructor is private, use Document::top_view() to get access to the top level View, then use either View::operator[], View::try_get(), or View::try_at() to access subsequent views.

template<typename T >
T json::View::as ( ) const

Parse View to typename T.

Warning
This only works if this View instance is a literal type. Will throw an error otherwise (which?).
Template Parameters
TThe type to parse View into. The build supported types are:
  • int (will remove decimals)
  • unsigned int (will remove decimals)
  • float
  • double
  • std::string
  • std::string_view
  • bool (anything that isnt false will return true)

However To add support for a custom type, define:

template<>
MyType View::as<MyType>() { ... }
