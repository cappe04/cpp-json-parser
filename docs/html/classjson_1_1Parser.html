Detailed Description

Parses JSON.

A class to parse JSON. In case of invalid JSON code an error message will be provided with Parser::get_erros(). The validity of the JSON can be check with Parser::get_status();

The JSON will be parsed and saved into a Document instance which can be exracted with Parser::get_document(). If this method isn't called the Parser instance will own the document and free it when destroyed.

Example:

// source = some std::shared_ptr to a const string
json::Parser parser(source);
parser.parse();
if(!parser.get_status()) {
std::cout << parser.get_error() << std::endl;
// Handle error
} else {
std::cout << parser.to_string() << std::endl; // prints json file.
}
